elder futhark

Hand-drawn Elder Futhark runes. Type Latin letters; the font turns them into runes.

Try it

The runes

Short runes (ᚲ, ᛃ, ᛜ) sit centred between the baseline and the top of the tall runes. Real runic characters (U+16A0–U+16F0) also work, e.g. pasting ᚠᚢᚦᚨᚱᚲ. The last three are word separators.

@font-face {
  font-family: "Elder Futhark";
  src: url("https://cdn.jsdelivr.net/gh/michaelthomasletts/elder_futhark@main/fonts/ElderFuthark-Regular.woff2") format("woff2");

  font-display: swap;
}
@font-face {
  font-family: "Elder Futhark";
  src: url("https://cdn.jsdelivr.net/gh/michaelthomasletts/elder_futhark@main/fonts/ElderFuthark-Bold.woff2") format("woff2");
  font-weight: 700;
  font-display: swap;
}

.runes {
  /* the fallback font supplies punctuation and digits the runes don't cover */
  font-family: "Elder Futhark", Georgia, serif;
}

/* optional: spell by sound (ph→ᚠ, qu→ᚲᚹ, x→ᚲᛊ, ei→ᛇ) */
.runes-phonetic { font-feature-settings: "ss01"; }
